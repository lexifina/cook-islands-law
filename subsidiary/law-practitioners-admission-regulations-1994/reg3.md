# 3 Application for admission
(1) Every application for admission must be lodged with the Registrar at least 6 weeks before the day on which the applicant desires to be admitted, unless the Registrar, for any special reason, directs an abridgement of that period.
(2) Every application for admission must be in the form numbered 15 in the Code of Civil Procedure 1981, with all necessary modifications.
(3) The contents of the application must be verified by affidavit or statutory declaration.
(4) There must be filed with the application 3 copies thereof, and copies of every document accompanying the same or referred to therein.
(5) Every application must set forth the circumstances in which the application is made, and the grounds therefor.
