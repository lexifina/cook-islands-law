# 118 Agent to make returns and be assessed as principal
(1) Every agent must make returns of the income in respect of which that person is an agent, and must be assessed thereon in the same manner as if that person were the principal, save that the agent is entitled to no special exemption or rebates from income tax other then such exemption or rebates (if any) as the principal may be entitled to.
(2) Every person liable to furnish a return as agent for any person must furnish a separate return for each person for whom that person is agent, in addition to that person’s own individual return.
