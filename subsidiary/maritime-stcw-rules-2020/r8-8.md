# 8.8 Use of simulators for training
8.8.1 The performance standards and other provisions set forth in section A-I/12 of the STCW Code and such other requirements as are required in section A of the STCW Code for any certificate concerned must be complied with in respect of—
(a) all mandatory simulator-based training:
(b) any assessment of competency required by section A of the STCW Code which is carried out by means of a simulator; and
(c) any demonstration, by means of a simulator, for continued proficiency required by section A of the STCW Code.
