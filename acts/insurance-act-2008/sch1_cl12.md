# 12 Existing domestic insurers and existing insurance intermediaries
Section 71 applies to, and with respect to, an existing domestic insurer and an existing insurance intermediary as if, in each case, it was a licensee, with the following modifications—
(a) subsection (1)(a)(i) is to be construed as referring to a contravention of a provision of the Act or the Code that applies to the existing domestic insurer or existing insurance intermediary; and
(b) subsection (1)(a)(v) does not apply; and
(c) subsection (1)(a)(vi) applies with the deletion of the words”, whether on making application for a licence or subsequent to the issue of the licence”; and
(d) subsection (2) does not apply; and
