# 17 Communication
(1) A land agent must communicate regularly with the client and keep the client well informed of matters relevant to the client’s particular transaction.
(2) A land agent must disclose all matters concerning the client’s affairs to the client unless to do so would be unlawful.
(3) A land agent must respond to inquiries from the client in a timely manner.
(4) A land agent must inform the client if there are any material and unexpected delays in a matter.
