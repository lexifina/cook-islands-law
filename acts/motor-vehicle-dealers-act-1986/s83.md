# 83 Application of Act to branch managers
(1) For the purposes of this Act, every branch manager is deemed to be a licensee.
(2) For the purposes of the foregoing provisions of this Part, if any motor vehicle to which this Part applies is sold at a branch office, the motor vehicle is deemed to have been sold by the branch manager and not by the licensee.
(3) In any case to which subsection (2) applies, for the purposes of section 37 the licensee is deemed to have guaranteed the compliance by the branch manager with this Part, and, in the event of default by the branch manager, the licensee is liable accordingly.
