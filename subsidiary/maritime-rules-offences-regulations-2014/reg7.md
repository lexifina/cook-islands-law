# 7 Strict liability
(1) In a prosecution for an offence it is not necessary for the prosecution to prove the defendant intended to commit an offence.
(2) It is a defence in any prosecution, if the defendant proves the defendant did not intend to commit the offence and that—
(a) if it is alleged that anything required to be done was not done, the defendant took all reasonable steps to ensure it was done:
(b) if it is alleged that anything prohibited was done, the defendant took all reasonable steps to ensure it was not done.
