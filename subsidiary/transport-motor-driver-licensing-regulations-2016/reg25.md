# 25 Testing fees
(1) The fees for driver licensing tests are—
(a) $10 for the police practical test:
(b) for any vehicle handling course,—
(i) $50 for motor cycles:
(ii) $50 for motor vehicles.
(2) An application for any test or course must be accompanied by the appropriate prescribed fee for that test or course.
(3) Each class of licence attracts a separate fee payable for each test or course.
