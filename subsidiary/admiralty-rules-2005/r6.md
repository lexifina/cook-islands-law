# 6 Forms
(1) The prescribed forms must be used wherever appropriate.
(2) If a form has not been prescribed for any application under these rules to the Court, the application must be in the form of an interlocutory application and any order made on that application must be in the form prescribed for an order made on an interlocutory application under these Rules.
(3) If subclause (2) does not apply, the parties may frame a form for the special purpose of the particular case or the Court may frame the form.
(4) Variations to a prescribed form are permitted if the circumstances of any particular case so require.
