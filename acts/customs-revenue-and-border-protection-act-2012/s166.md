# 166 Use of unique user identifier
(1) Where information is transmitted to a Customs automated system using a unique user identifier issued to a registered user by the Comptroller for that purpose, the transmission of that information is, in the absence of proof to the contrary, sufficient evidence that the registered user to whom the unique user identifier has been issued has transmitted that information.
(2) Where a unique user identifier is used by an individual who is not entitled to use it, subsection (1) does not apply if the registered user to whom the unique user identifier was issued has, prior to the unauthorised use of that unique user identifier, notified Customs that the unique user identifier is no longer secure.
[Section 166(1): amended, on 1 July 2020, by section 13 of the Customs Legislation Act 2020 (2020 No 9) .]
