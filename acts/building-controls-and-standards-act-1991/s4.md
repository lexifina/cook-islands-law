# 4 National Building Code
(1) There shall be a National Building Code to prescribe performance requirements with which buildings and their demolition must comply.
(2) The National Building Code applies to all buildings except those exempted under this Act.
(3) The Queen’s Representative may by Order in Executive Council declare any code, including any international or other overseas code, to be the National Building Code for the purposes of this Act, and may in a like manner amend or revoke any such declaration.
