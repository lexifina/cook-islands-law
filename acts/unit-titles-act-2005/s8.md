# 8 Existing easements affecting land
(1) The confirmation of a unit plan has no effect on any easement or restriction as to user which the land to which the plan relates is subject, or on any easement or restriction as to user which is appurtenant to the land to which the plan relates.
(2) The Court must require all such easements and restrictions as to user to be recorded (by diagram, words, or otherwise) on the unit plan.
