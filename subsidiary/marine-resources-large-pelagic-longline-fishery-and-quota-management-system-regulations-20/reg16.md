# 16 Discarded catches
(1) Vessels must retain all species of the large pelagic longline fishery except in the following exceptional circumstances the—
(a) haul for the last fishing set has no storage space on board:
(b) catch is unfit for human consumption for reasons other than size.
(2) Any catch discarded under section 16(1) must report the discarding event and reason for discarding, to the Secretary.
