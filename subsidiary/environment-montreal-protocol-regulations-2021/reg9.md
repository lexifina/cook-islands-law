# 9 Prohibition on manufacture of controlled substances and certain goods
The manufacture in the Cook Islands of the following substances or goods is prohibited:
(a) any controlled substance:
(b) any aerosol spray that contains any controlled substance:
(c) any plastic foam, or any goods that contain plastic foam, that is or are manufactured using any controlled substance:
(d) any dry-cleaning machine that contains or is designed to use any controlled substance as a solvent:
(e) any fire extinguisher that contains any controlled substance.
